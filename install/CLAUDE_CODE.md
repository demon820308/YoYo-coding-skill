# Claude Code｜当前工作区安装

Claude Code 项目级 Skill 目录为仓库内 `.claude/skills/`。将整个 `yoyo` Skill 文件夹放到：

```text
<项目根目录>/.claude/skills/yoyo/SKILL.md
```

本目录是项目级位置。不要安装到用户目录 `~/.claude/skills/`。

如果项目根目录已有 `.claude/skills/yoyo/`，先比较和备份，不覆盖用户改动。项目档案放在 `<项目根目录>/.yoyo/`，不要放进 Skill 目录。

参考：Anthropic Agent Skills 文档 https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview
