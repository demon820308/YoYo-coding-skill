# 当前项目 Agent 规则

> 本文件是当前仓库 Agent 行为规则唯一事实源。平台根目录的 `AGENTS.md`、`CLAUDE.md` 等只建立短指针，不复制全文。

## 工作原则
- 修改前检查 Git 状态和用户已有改动。
- 先阅读与任务相关的代码、文档和 `.yoyo/PROJECT_RULES.md`。
- 只修改授权范围内文件；无关问题单独报告。
- 不得泄露密钥、令牌或敏感数据。
- 测试必须真实执行并报告结果；交付前检查实际 Diff。

## 默认需用户明确授权
- 删除/覆盖用户数据或未提交修改。
- 重置/强推 Git 历史。
- 生产环境写入、发布或停机。
- 不可逆数据库迁移。
- 批量升级核心依赖或替换核心架构。
- 修改权限边界或密钥配置。

## 项目特定约束
- 在此填写，不复制通用 Skill 全文。
