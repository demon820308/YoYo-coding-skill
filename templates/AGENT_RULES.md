# AGENT_RULES.md

> 本文件是本仓库 Agent 行为规则的唯一事实源。所用平台若只自动读取 `AGENTS.md`、`CLAUDE.md` 等其他文件名，按 SKILL.md §9.1 桥接：平台文件只放指向本文件的指针＋五条铁律摘要（或在单平台项目中以平台文件为本体、二选一），不许复制本文件全文另存第二份。

## 工作原则
- 修改前检查 Git 状态和用户已有改动。
- 先阅读与任务相关的代码和文档。
- 遵循 PROJECT_RULES.md。
- 只修改任务范围内文件；无关问题单独报告。
- 不得泄露密钥、令牌或敏感数据。

## 默认禁止（需用户明确授权）
- 删除/覆盖用户数据或未提交修改。
- 重置/强推 Git 历史。
- 生产环境写入、发布或停机。
- 不可逆数据库迁移。
- 批量升级核心依赖或替换核心架构。
- 修改权限边界或密钥配置。

## 任务执行
- 中高风险任务先提交计划。
- 测试必须真实执行并报告结果。
- 完成前检查实际 Diff。
- 报告未验证项、风险和恢复方式。

## 项目特定约束
- 在此补充，不重复复制通用 Skill 全文。
