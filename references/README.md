# 参考规范目录说明

本目录只保留 V1.5 当前选定的运行时规范来源：

1. 软件工程规范-通用复用版-增强版：通用技术工程规则。
2. 项目实施与持续验收规范 V1.0：实施过程、阶段门禁、证据与交付。
3. 项目启动规范：项目结构和骨架专项规则。
4. 三端规范 V1.1：Windows/macOS/Linux 桌面多端专项规则。
5. UI 设计质量与反模板化规范：界面设计与 UI 验收专项规则。

前四份专业/过程规范的适用边界由 `../core/specification-dispatch.md` 管理。每个任务只加载适用文件和相关章节。

V1.4 中曾并列打包的《通用软件工程规范 V2.0》《AI Agent 通用工程治理规范 V1.0》《现代软件工程与 AI Agent 研发治理体系 V1.0》不再作为 V1.5 运行时并列权威文件，以免重复和优先级混乱；如需追溯，可从用户原始资料单独查阅。该调整不修改、不删除用户原始文档。

除 YoYo 自身的调度摘要外，以上原始规范正文均按来源文件原样保留，不擅自改写条款。
