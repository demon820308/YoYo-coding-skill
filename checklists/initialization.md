# 项目初始化与接管检查清单

- [ ] 确认当前项目根目录与工作区边界
- [ ] 区分项目生命周期状态与本次任务模式
- [ ] 确认用户目标、非目标和验收条件
- [ ] 检查 Git 分支、工作区状态和用户已有修改
- [ ] 识别技术栈、构建、测试和启动方式；未知项不猜测
- [ ] 识别数据、安全、生产环境和恢复风险
- [ ] 检查是否已有项目级 YoYo Skill；升级前先比较，不覆盖用户改动
- [ ] 检查是否已有 `.yoyo/` 项目档案；先读取，不重复创建、不覆盖
- [ ] 若需安装，使用当前平台的项目级 Skill 目录，不使用用户级/系统级目录
- [ ] 确认项目级 Skill 安装不被误认为安全沙箱，实际权限由平台配置控制
- [ ] 新建项目按需创建 `.yoyo/`；接管项目先建立基线，不追溯性补造历史记录
- [ ] 仅按适用条件启用项目启动、桌面三端和 UI 专项规范
- [ ] 在 `.yoyo/PROJECT_PROFILE.yaml` 记录规范采纳状态、版本和 N/A 原因
- [ ] 若平台需要根目录规则桥接，使用指针指向 `.yoyo/AGENT_RULES.md`，不复制全文
- [ ] 初始化/接管阶段未擅自修改业务代码
