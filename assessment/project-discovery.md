# 项目发现与盘点

## 只读发现清单

1. 根目录与主要子目录
2. README、贡献指南、项目规则和架构文档
3. 语言、框架、包管理器、锁文件
4. 应用入口、服务入口、CLI 入口
5. 构建、测试、Lint、类型检查和启动脚本
6. 数据库、缓存、消息队列和文件存储
7. API、第三方服务和外部系统
8. 环境变量名称（不读取/输出真实密钥）
9. Docker、CI、部署和基础设施配置
10. Git 分支、工作区状态、近期变更

## 记录方式

每个结论标记来源：
- `已验证`：通过文件、命令或运行结果直接确认。
- `文档声明`：项目文档如此描述，尚未实际验证。
- `推断`：由代码结构推断，需谨慎。
- `未知`：当前无法确认。

不要把推断写成事实。
